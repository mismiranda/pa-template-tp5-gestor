\# Concepto de Gestor (Manager) en POO ## 1\. Definición y Propósito En Programación Orientada a Objetos, un \*\*Gestor\*\* (o \*manager\*) es una clase u objeto encargado de administrar, coordinar y manejar recursos, estados o procesos dentro de un sistema [1]. Su objetivo principal es encapsular la lógica asociada al control de esos recursos [1]. ### Ventajas principales: \* \*\*Centralización:\*\* Centraliza la administración de los recursos en un único punto [2]. \* \*\*Reutilización:\*\* Facilita la reutilización del código en distintos componentes del sistema [2]. \* \*\*Seguridad:\*\* Garantiza el manejo adecuado de recursos críticos [2]. --- ## 2\. Responsabilidades y Tipos de Gestores Según el propósito del sistema, los gestores pueden asumir distintas funciones [2]: \* \*\*Gestión de recursos:\*\* Controlan el ciclo de vida (apertura, cierre y reutilización) de archivos, memoria o conexiones a bases de datos [2]. \* \*\*Gestión de estado:\*\* Administran el estado de un objeto o grupo de objetos (por ejemplo, el estado de una sesión de usuario) [2, 3]. \* \*\*Control de procesos:\*\* Coordinan el flujo de procesos o hilos concurrentes [3]. \* \*\*Delegación de tareas:\*\* Notifican y envían llamadas a componentes especializados encargados de reaccionar a eventos [3, 4]. --- ## 3\. Estructura Básica de un Gestor La arquitectura de cualquier gestor se compone de dos elementos fundamentales [4]: 1\. \*\*Un Contenedor (\*container\*):\*\* Estructura de datos (arreglo, lista, árbol, base de datos, etc.) que almacena la colección de objetos [4, 5]. 2\. \*\*Conjunto de Operaciones (Métodos):\*\* Servicios que permiten manipular la colección [4]. ### Operaciones elementales: \* \*\*Agregar:\*\* Añadir nuevos objetos al contenedor [5]. \* \*\*Eliminar:\*\* Remover objetos del contenedor [5]. \* \*\*Buscar:\*\* Localizar un objeto específico [5]. \* \*\*Recorrer:\*\* Iterar sobre el contenedor para procesar o listar elementos [5]. &gt; \*\*Relación de diseño:\*\* La relación entre la clase Gestor y los objetos administrados es de \*\*Composición\*\* [6]. En Java, se implementa habitualmente encapsulando un arreglo como contenedor primario [5]. --- ## 4\. Ejemplos de Aplicación ### Ejemplo 1: Lista de Contactos (\`ContactList\`) Ejemplo de un cliente de correo que administra agenda de contactos [6]: \* \*\*Clase de entidad (\`Contact\`):\*\* Almacena los atributos individuales como \`name\` y \`mail\` [6]. \* \*\*Clase Gestor (\`ContactList\`):\*\* Encapsula el arreglo \`Contact[] contacts\`, gestionando la capacidad (\`size\`) y la siguiente posición disponible (\`next\`) [6, 7]. Proporciona métodos para añadir (\`addContact\`), buscar (\`searchContact\`), eliminar (\`removeContact\`) y redimensionar el arreglo (\`enlarge\`) para reutilizar posiciones vacías [6-9]. \`\`\`java // Clase de entidad administrada public class Contact { private String name; private String mail; public Contact(String name, String mail) { this.name = name; this.mail = mail; } public String getName() { return name; } public void setName(String name) { this.name = name; } public String getMail() { return mail; } public void setMail(String mail) { this.mail = mail; } } // Clase Gestor public class ContactList { private Contact[] contacts; private int size; private int next; public ContactList(int n) { this.size = n; this.contacts = new Contact[size]; this.next = 0; } public void addContact(Contact contact) { if (!(this.next &lt; this.size)) { this.enlarge(); } this.contacts[next] = contact; this.next++; } public boolean searchContact(String contactName) { boolean found = false; int count = 0; while (!found &amp;&amp; count &lt; next) { if (contacts[count] != null &amp;&amp; contacts[count].getName().equals(contactName)) { found = true; } count++; } return found; } public void removeContact(String contactName) { boolean found = false; int count = 0; while (!found &amp;&amp; count &lt; next) { if (contacts[count] != null &amp;&amp; contacts[count].getName().equals(contactName)) { found = true; } count++; } if (found) { contacts[count - 1] = null; } } private void enlarge() { int count2 = 0; Contact[] aux = new Contact[size + 100]; for (int count1 = 0; count1 &lt; size; count1++) { if (contacts[count1] != null) { aux[count2] = contacts[count1]; count2++; } } this.contacts = aux; this.next = count2; this.size = size + 100; } }
